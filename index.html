أداة تنظيف ملفات CSV بـ Python مع تقرير قرارات موثّق

Python / Pandas

أداة بايثون صغيرة تنظّف ملفات CSV الفوضوية وتشرح كل قرار اتخذته في تقرير مكتوب. صُممت لأصحاب المتاجر الإلكترونية والأعمال التي تتعامل مع بيانات غير مرتبة: تكرارات، خانات فارغة، تواريخ بصيغ مختلفة، وأرقام مشكوك فيها.

رسم توضيحي للفكرة، وليس لقطة من الأداة.

الفكرة

ماذا تفعل الأداة؟

تقرأ الأداة أي ملف CSV، وتنفّذ خطوات تنظيف أساسية بشكل تلقائي، ثم تكتب نسختين: ملفًا نظيفًا جاهزًا للاستخدام، وتقريرًا نصيًا يسجّل كل قرار حتى يراجعه صاحب البيانات.

الفكرة الأساسية أن التنظيف لا يكون صندوقًا أسود: ما يمكن حسمه آليًا يُحسم، وما يحتاج حكمًا بشريًا يُميَّز ويُترك للمراجعة بدل أن يُحذف في صمت.

القدرات

المميزات الخمس

  1. إزالة الصفوف المكررة تمامًا مع تسجيل عددها في التقرير.
  2. معالجة القيم الناقصة: الأعمدة الرقمية تُملأ بالوسيط (median)، والنصية بقيمة Unknown واضحة.
  3. توحيد التواريخ إلى صيغة واحدة YYYY-MM-DD، بما في ذلك الصيغ التي يأتي فيها اليوم قبل الشهر، مع إبقاء القيم غير القابلة للقراءة كما هي للمراجعة.
  4. تمييز القيم المتطرفة والسالبة للمراجعة بدلًا من حذفها بصمت، لأن الكمية السالبة قد تكون مرتجعًا حقيقيًا، والقرار الأخير لصاحب البيانات.
  5. تقرير قرارات موثّق يُكتب مع كل تشغيل ويسجّل كل خطوة وكل قيمة تأثرت.

الكود المصدري الكامل

"""
CSV Cleaner - a small, explainable data-cleaning tool.

What it does, step by step:
  1. Loads any CSV file.
  2. Removes exact duplicate rows.
  3. Reports and fills missing values (numbers -> median, text -> "Unknown").
  4. Parses date columns into one format (YYYY-MM-DD), flags unparseable dates.
  5. Flags numeric outliers with the IQR rule (does NOT delete them -
     e.g. a negative quantity might be a legitimate return, so we mark it
     and let a human decide).
  6. Writes a cleaned CSV and a plain-text report of every decision.

Usage:
  python csv_cleaner.py input.csv --out cleaned.csv --report report.txt
"""

import argparse
import sys

import pandas as pd


def find_date_columns(df):
    """Columns whose name suggests a date."""
    return [c for c in df.columns if "date" in c.lower()]


def main():
    parser = argparse.ArgumentParser(description="Clean a CSV file with a full report.")
    parser.add_argument("input", help="Path to the input CSV")
    parser.add_argument("--out", default="cleaned.csv", help="Cleaned CSV path")
    parser.add_argument("--report", default="report.txt", help="Report path")
    args = parser.parse_args()

    report = []
    log = report.append

    df = pd.read_csv(args.input)
    log(f"Loaded {len(df)} rows, {len(df.columns)} columns: {list(df.columns)}")

    # 1. Duplicates
    dupes = df.duplicated().sum()
    df = df.drop_duplicates()
    log(f"Removed {dupes} exact duplicate row(s).")

    # 2. Missing values
    for col in df.columns:
        missing = df[col].isna().sum()
        if missing == 0:
            continue
        if pd.api.types.is_numeric_dtype(df[col]):
            fill = df[col].median()
            df[col] = df[col].fillna(fill)
            log(f"Column '{col}': filled {missing} missing value(s) with the median ({fill}).")
        else:
            df[col] = df[col].fillna("Unknown")
            log(f"Column '{col}': filled {missing} missing value(s) with 'Unknown'.")

    # 3. Dates
    for col in find_date_columns(df):
        parsed = pd.to_datetime(df[col], errors="coerce", dayfirst=False, format="mixed")
        # Retry failures with day-first order (common outside the US).
        retry = pd.to_datetime(df[col], errors="coerce", dayfirst=True, format="mixed")
        recovered = parsed.isna() & retry.notna()
        parsed = parsed.fillna(retry)
        bad = parsed.isna() & df[col].notna()
        log(f"Column '{col}': parsed {parsed.notna().sum()} date(s) "
            f"({recovered.sum()} recovered with day-first order); "
            f"{bad.sum()} value(s) kept as-is for review: {list(df.loc[bad, col])}")
        df[col] = parsed.dt.strftime("%Y-%m-%d").fillna(df[col])

    # 4. Outliers (flag, never silently delete)
    for col in df.select_dtypes("number").columns:
        q1, q3 = df[col].quantile(0.25), df[col].quantile(0.75)
        iqr = q3 - q1
        low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
        outliers = df[(df[col] < low) | (df[col] > high)]
        negatives = df[df[col] < 0]
        if not outliers.empty:
            log(f"Column '{col}': {len(outliers)} outlier(s) outside [{low:.1f}, {high:.1f}] "
                f"-> values {list(outliers[col])}. Flagged for review, NOT removed.")
        if not negatives.empty:
            log(f"Column '{col}': {len(negatives)} negative value(s) {list(negatives[col])}. "
                f"Could be returns/cancellations - confirm with the client before changing.")

    df.to_csv(args.out, index=False)
    log(f"Wrote {len(df)} cleaned rows to {args.out}.")

    text = "\n".join(report)
    with open(args.report, "w", encoding="utf-8") as f:
        f.write(text + "\n")
    print(text)


if __name__ == "__main__":
    sys.exit(main())

بعد تثبيت pandas، شغّل الأداة على أي ملف:

python csv_cleaner.py اسم_الملف.csv

ويمكن تحديد أسماء ملفات الإخراج بإضافة خيارات سطر الأوامر:

python csv_cleaner.py input.csv --out cleaned.csv --report report.txt
