أداة سحب بيانات الكتب من الويب إلى ملف CSV بـ Python

Python / Requests / BeautifulSoup

سكريبت بايثون يجمع بيانات الكتب من صفحات كتالوج ويب (العنوان والسعر والتقييم وحالة التوفر) ويحفظها في ملف CSV نظيف ومنظم. صُمم لكل من يحتاج تحويل بيانات مبعثرة على صفحات موقع إلى جدول جاهز للتحليل أو التسليم.

رسم توضيحي للفكرة، وليس لقطة من الأداة.

الفكرة

ماذا تفعل الأداة؟

تزور الأداة صفحات الكتالوج صفحةً صفحة، تقرأ بطاقة كل كتاب، وتستخرج منها أربع حقول: العنوان، السعر، التقييم بالنجوم، وحالة التوفر. بعدها تكتب كل شيء في ملف CSV مرتب بأعمدة واضحة.

السكريبت مُجرب فعليًا على موقع books.toscrape.com، وهو موقع مخصص أصلًا للتدريب على سحب البيانات، فالبيانات المعروضة هنا بيانات تدريب تجريبية وليست بيانات عميل. الكود معمول بطريقة عامة بحيث يتعدل بسهولة لأي موقع آخر يسمح بالسحب.

القدرات

المميزات الخمس

  1. استخراج العنوان والسعر والتقييم بالنجوم وحالة التوفر لكل كتاب، مع تحويل التقييم من كلمة إلى رقم.
  2. تتبع رابط «التالي» تلقائيًا للتنقل بين صفحات الكتالوج حتى عدد الصفحات المطلوب.
  3. احترام الخادم: مهلة قابلة للضبط بين الطلبات (ثانية واحدة افتراضيًا) وعدد صفحات محدود، حتى لا يضغط السكربت على الموقع.
  4. ملف CSV نظيف بترميز UTF-8 بأعمدة جاهزة للفتح في Excel أو pandas مباشرة.
  5. ملخص تشغيل بعد كل مرة: عدد الصفحات والكتب، أقل وأعلى ومتوسط سعر، وتوزيع التقييمات.

قابل للنسخ والتعديل

الكود المصدري الكامل

"""
Books Scraper - collect book data from a web catalog into a clean CSV.

What it does, step by step:
  1. Downloads catalog pages from books.toscrape.com, a site built
     specifically for practicing web scraping (scraping it is allowed).
  2. Parses every book card on each page: title, price, star rating,
     and availability.
  3. Follows the "next" link automatically, so it can walk the whole
     catalog or stop after a fixed number of pages.
  4. Writes the results to a clean, ready-to-use CSV file.
  5. Prints a short run summary: pages fetched, books collected,
     price range, and rating distribution.

The scraper is polite by default: it waits between requests and uses a
modest page limit, so it never hammers the server.

Usage:
  python books_scraper.py                  # 5 pages -> books.csv
  python books_scraper.py --pages 3 --out books.csv --delay 1.0
"""

import argparse
import csv
import sys
import time
from urllib.parse import urljoin

import requests
from bs4 import BeautifulSoup

BASE_URL = "https://books.toscrape.com/"

# The site stores the star rating as a word in the CSS class,
# e.g. <p class="star-rating Three">.
RATING_WORDS = {"One": 1, "Two": 2, "Three": 3, "Four": 4, "Five": 5}

HEADERS = {"User-Agent": "books-scraper-demo/1.0 (learning project)"}


def parse_book(article):
    """Extract one book's data from its HTML card."""
    title = article.h3.a["title"].strip()

    price_text = article.select_one(".price_color").get_text(strip=True)
    price = float(price_text.lstrip("£"))

    rating_class = article.select_one(".star-rating")["class"]
    rating = next((RATING_WORDS[c] for c in rating_class if c in RATING_WORDS), None)

    availability = article.select_one(".availability").get_text(strip=True)

    return {
        "title": title,
        "price_gbp": price,
        "rating": rating,
        "availability": availability,
    }


def scrape_page(session, url):
    """Scrape one catalog page. Returns (books, next_page_url_or_None)."""
    response = session.get(url, timeout=15)
    response.raise_for_status()
    response.encoding = "utf-8"  # the site is UTF-8; don't let requests guess
    soup = BeautifulSoup(response.text, "html.parser")

    books = [parse_book(a) for a in soup.select("article.product_pod")]

    next_link = soup.select_one("li.next a")
    next_url = urljoin(url, next_link["href"]) if next_link else None
    return books, next_url


def main():
    parser = argparse.ArgumentParser(
        description="Scrape book data from books.toscrape.com into a CSV file."
    )
    parser.add_argument("--pages", type=int, default=5,
                        help="Maximum number of catalog pages to scrape (default: 5)")
    parser.add_argument("--out", default="books.csv",
                        help="Output CSV path (default: books.csv)")
    parser.add_argument("--delay", type=float, default=1.0,
                        help="Seconds to wait between requests (default: 1.0)")
    args = parser.parse_args()

    books = []
    url = BASE_URL
    pages_done = 0
    started = time.time()

    with requests.Session() as session:
        session.headers.update(HEADERS)
        while url and pages_done < args.pages:
            page_books, url = scrape_page(session, url)
            books.extend(page_books)
            pages_done += 1
            print(f"Page {pages_done}: collected {len(page_books)} books "
                  f"(total so far: {len(books)})")
            if url and pages_done < args.pages:
                time.sleep(args.delay)  # be polite

    with open(args.out, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=["title", "price_gbp", "rating", "availability"])
        writer.writeheader()
        writer.writerows(books)

    # ---- Run summary ----
    prices = [b["price_gbp"] for b in books]
    ratings = {stars: sum(1 for b in books if b["rating"] == stars) for stars in range(1, 6)}
    elapsed = time.time() - started

    print()
    print("Run summary")
    print("-----------")
    print(f"Pages scraped : {pages_done}")
    print(f"Books collected: {len(books)}")
    print(f"Prices (GBP)  : min {min(prices):.2f} / max {max(prices):.2f} "
          f"/ avg {sum(prices) / len(prices):.2f}")
    print("Ratings       : " + ", ".join(f"{s}* = {ratings[s]}" for s in range(5, 0, -1)))
    print(f"Elapsed       : {elapsed:.1f}s (delay between pages: {args.delay}s)")
    print(f"Output        : {args.out} ({len(books)} rows + header)")


if __name__ == "__main__":
    sys.exit(main())
